# Безопасность / Security

## Как сообщить об уязвимости

Не создавайте публичный issue. Откройте вкладку **Security** этого репозитория и нажмите **Report a vulnerability** — сообщение увидит только владелец. Опишите, что затронуто, как воспроизвести и чем это грозит. Ответ — в течение 7 дней.

Не прикладывайте реальные персональные данные покупателей, пароли и токены.

## Reporting a vulnerability

Please do not open a public issue. Use **Security** → **Report a vulnerability** in this repository to send a private report with the affected area, reproduction steps and impact. We aim to reply within 7 days.

## Поддерживаемые версии / Supported versions

Исправления выпускаются только для ветки `main`. / Fixes are released for the `main` branch only.
