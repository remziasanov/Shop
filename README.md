# Shop: интернет-магазин на Laravel 13 и Filament 5

Интернет-магазин для виртуального хостинга Beget. Витрина написана на Blade, Tailwind CSS 4, Alpine.js и Livewire, админ-панель — на Filament 5. Фоновые задачи (планировщик и очередь) работают без демонов: через CronTab Beget и очередь в базе данных. Требования к проекту описаны в `docs/TZ.html`.

## Возможности

По разделам ТЗ:

- **Витрина (раздел 5):** главная страница с настраиваемыми блоками, каталог с категориями, фильтрами и сортировкой, поиск с подсказками, карточка товара, режимы продаж, корзина и оформление заказа, резервирование товара, заявка-запрос, страницы политики и согласия (152-ФЗ), SEO (человекопонятные адреса, редиректы со старых адресов, `sitemap.xml`, `robots.txt`).
- **Админ-панель (раздел 6):** дашборд, настройки магазина, категории, товары и фотографии (сжатие в WebP), ценообразование (наценки, скидки, правила по периодам), заказы и заявки, импорт товаров из Excel с фотографиями из ZIP, экспорт каталога в Excel, страницы и меню, пользователи с ролями «администратор» и «менеджер», страница «Система» с проверкой окружения.
- **Уведомления (раздел 9):** о новых заказах, резервах и заявках — по email и в Telegram.
- **Фоновые задачи (раздел 8):** резервы, пересчёт цен, карта сайта, очистка и уведомления выполняются по расписанию.

### Версия 2.0

- **Роли сотрудников (RB):** настраиваемые роли и права («Контент-менеджер», «Менеджер» и свои), журнал действий, защита последнего администратора.
- **Группы покупателей и личный кабинет (CG, CA):** регистрация с кодом из письма, вход по паролю или коду, адреса, реквизиты компании, история заказов и «Повторить заказ», уведомления, смена email и удаление аккаунта с обезличиванием заказов; группы «Гость», «Розница», «Опт» управляют видимостью разделов и категорий, ценами, минимальной суммой, доставкой и оплатой; заявки на опт с решением менеджера.
- **Групповые и оптовые цены (GP):** точные цены групп, скидка группы, ступени по количеству с подсказкой «Ещё N шт — и цена станет…», прайс-лист группы в Excel, снимок источника цены в заказе.
- **Характеристики и фильтры (FL):** справочник характеристик, фильтры категорий с счётчиками, ссылки с параметрами, правила индексации страниц фильтров.
- **Модификации товара (VR):** опции «Цвет», «Размер» и др., собственные артикулы, цены и остатки модификаций, выбор на витрине плашками и кнопками, импорт и экспорт модификаций.
- **Промокоды и промо-ссылки (PM):** процент, сумма, бесплатная доставка, партии одноразовых кодов с выгрузкой в Excel, ссылки `/go/…` с UTM-метками и статистикой кликов, заказов и выручки.
- **Резерв нескольких товаров через корзину (MR) и редактирование заказа (OE):** предпросмотр «было / станет», влияние на остатки, журнал изменений, письмо покупателю, создание заказа из заявки.
- **Возрастное ограничение (AG):** плашка «Вам уже исполнилось N лет?» для всего сайта или только для товаров и категорий с ограничением; поисковые роботы видят страницы целиком.
- **Выгрузка истории заказов и бланк/счёт (CX):** PDF и Excel из кабинета, большие выгрузки — фоновой задачей со ссылкой на 24 часа, «Счёт / бланк заказа» для оптовых групп, печатная форма в админке.

## Требования

- PHP 8.3 или новее (расширения: `pdo_mysql`, `pdo_sqlite`, `mbstring`, `intl`, `gd` с поддержкой WebP, `zip`, `fileinfo`, `bcmath`, `openssl`, `curl`, `xml`, `dom`, `ctype`, `tokenizer`). Расширения `mbstring`, `dom` и `gd`, а также запись в `storage/fonts` нужны для PDF (dompdf, версия 2.0); `shop:doctor` проверяет их.
- Composer 2.
- Node.js 22 и npm — только для сборки фронтенда. На сервере Node.js не нужен: сборка выполняется в GitHub Actions.
- MySQL 8.0 в продакшене (на Beget); для локального запуска и тестов достаточно SQLite.

## Локальный запуск

Инструкция для быстрого старта на SQLite.

```bash
git clone <адрес репозитория> shop
cd shop
composer install
npm ci && npm run build
cp .env.example .env
```

Откройте `.env` и измените значения для локальной работы:

```ini
APP_ENV=local
APP_DEBUG=true
APP_URL=http://127.0.0.1:8000
SESSION_SECURE_COOKIE=false
DB_CONNECTION=sqlite
```

Строку `DB_DATABASE=...` из `.env.example` **удалите** (или закомментируйте): без неё Laravel использует файл `database/database.sqlite`. Если оставить `DB_DATABASE=login_shop`, команда `migrate` предложит создать файл `login_shop` в корне проекта. Можно вместо удаления указать абсолютный путь, например `DB_DATABASE=/полный/путь/к/shop/database/database.sqlite`. Правка одной командой:

```bash
sed -i '/^DB_DATABASE=/d' .env
```

`SESSION_SECURE_COOKIE=false` обязателен на `http://127.0.0.1`: с `true` браузер не сохранит cookie, и вход в админ-панель завершится ошибкой 419.

Затем выполните команды:

```bash
touch database/database.sqlite
php artisan key:generate
php artisan migrate --seed
php artisan shop:demo
php artisan storage:link
php artisan shop:create-admin
php artisan serve
```

- `shop:demo` создаёт демонстрационный каталог с вымышленными товарами и сгенерированными фотографиями, а также данные версии 2.0: группу «Опт» с оптовыми ценами и ступенями (10+ шт. и 50+ шт.), категорию «Оптовые наборы», скрытую от розницы, футболку «Север» с 12 модификациями (Цвет × Размер), характеристики и фильтры категорий, промокод `DEMO10` и промо-ссылку `/go/demo-futbolka`. Команду можно запускать повторно: данные обновляются, дубликаты не создаются.
- `shop:create-admin` спрашивает имя, адрес электронной почты и пароль (не менее 10 символов). Для локальной демонстрации укажите, например, `admin@example.com` и пароль, который вы придумали. Учётные данные не коммитятся в репозиторий и не предназначены для продакшена.

После `php artisan serve` витрина открывается по адресу `http://127.0.0.1:8000`, админ-панель — по адресу `http://127.0.0.1:8000/admin` (путь задаётся переменной `ADMIN_PATH`).

Фоновые задачи локально. Очередь можно обработать разово, планировщик можно запускать в отдельном окне терминала:

```bash
php artisan queue:work --stop-when-empty
```

```bash
php artisan schedule:work
```

## Проверки

Перед коммитом и в CI запускаются:

```bash
php artisan test
vendor/bin/pint --test
vendor/bin/phpstan analyse
npm run build
```

Проверка миграций на MySQL 8.0 (нужен локальный сервер MySQL, настройки песочницы — в `docs/DEV_ENV.md`):

```bash
DB_CONNECTION=mysql php artisan migrate:fresh --seed
```

Исправить стиль кода автоматически можно командой `vendor/bin/pint` (без `--test`).

## Структура проекта

- `app/Enums` — перечисления (статусы заказов, режимы продаж и т. д.), хранятся в базе как строки.
- `app/Models` — модели Eloquent.
- `app/Services` — бизнес-логика по направлениям: `Pricing`, `Sales`, `Cart`, `Orders`, `Stock`, `Import`, `Export`, `Media`, `Notifications`, `Access`, `Customers`, `Promo`, `Variants`, `Catalog`, `Age`, `Users`. Блокировка и изменение остатков — только через `StockService`.
- `app/Jobs` — задачи очереди.
- `app/Settings` — настройки магазина (spatie/laravel-settings), значения по умолчанию — в миграциях настроек.
- `app/Filament` — ресурсы и страницы админ-панели.
- `app/Livewire` и `app/Http/Controllers/Storefront` — интерактивные компоненты и контроллеры витрины.
- `app/Console/Commands` — команды `shop:*`.
- `resources/views/storefront` — шаблоны витрины, `resources/views/mail` — письма.
- `lang/ru` — все тексты интерфейса (`__('shop.…')`).
- `database/migrations`, `database/seeders`, `database/factories` — схема базы, начальные данные и фабрики для тестов.
- `examples/` — шаблон импорта и демонстрационные файлы (`import-demo.xlsx`, `import-demo-photos.zip`, `import-variants.xlsx` — товар с модификациями: футболка «Цвет × Размер» и обычный товар).
- `tests/` — тесты на Pest. Сценарии приёмки версии 2.0 (раздел 14 ТЗ, сценарии 11–21) — `tests/Feature/Acceptance/V2ScenariosTest.php`, требования качества NF-50…NF-57 — `tests/Feature/Acceptance/V2QualityTest.php`; то, что нельзя проверить тестом, — ручной чек-лист в `docs/PROGRESS.md` (этап 15).
- `.github/workflows/` — `ci.yml` (проверки и тесты) и `deploy.yml` (ручной деплой на Beget).

## Документация

- `docs/TZ.html` — техническое задание: единственный источник требований.
- `docs/PROGRESS.md` — ход работ по этапам.
- `docs/DECISIONS.md` — журнал решений: контекст, выбор и отвергнутые варианты.
- `docs/DEV_ENV.md` — окружение разработки и песочница.
- `docs/DEPLOY_BEGET.md` — пошаговое развёртывание на Beget для владельца магазина.
- `docs/HOSTING_ALTERNATIVES.md` — куда ещё можно разместить магазин (аналоги Beget и VPS), как перенастроить деплой и частые проблемы.
- `CLAUDE.md` — правила работы с кодом и конвенции проекта.

## Деплой

Развёртывание на Beget описано в [docs/DEPLOY_BEGET.md](docs/DEPLOY_BEGET.md): регистрация и тариф, сайт и PHP 8.3, база MySQL, SSH-ключ, секреты GitHub, первоначальная настройка `.env`, две задачи CronTab, SSL и почта, проверка, обновление, откат, резервные копии и частые проблемы. Деплой запускается вручную: в GitHub Actions выберите workflow **Deploy** и сайт. Как развернуть ещё один сайт на Beget из этого же репозитория (отдельное окружение GitHub со своими секретами и одна строка в `deploy.yml`) — раздел 13 в [docs/DEPLOY_BEGET.md](docs/DEPLOY_BEGET.md). Другие хостинги (Timeweb, Sprinthost, REG.RU, VPS) — [docs/HOSTING_ALTERNATIVES.md](docs/HOSTING_ALTERNATIVES.md).

## Команды artisan `shop:*`

Список команд — `php artisan list shop`.

| Команда | Описание | Опции |
|---|---|---|
| `shop:anonymize-customers` | Обезличивание покупателей, запросивших удаление аккаунта, по истечении срока отмены (CA-16) | — |
| `shop:attributes-migrate` | Перенос характеристик товаров из JSON в таблицы (FL-04) | `--dry-run` (только отчёт) |
| `shop:attributes-restore-json` | Возврат исходных JSON-характеристик из резервной копии миграции (FL-04) | `--product=ID` |
| `shop:build-price-lists` | Сборка оптовых прайс-листов групп покупателей (CG-17) | `--sync` (сразу, без очереди) |
| `shop:cleanup` | Удаление старых корзин, файлов импорта и экспорта (в том числе выгрузок покупателей с истёкшим сроком) и брошенных загрузок (раздел 8 ТЗ) | `--exports` (только просроченные выгрузки) |
| `shop:create-admin` | Создание администратора (AD-02) | `--name`, `--email`, `--password` (не менее 10 символов) |
| `shop:demo` | Создание демонстрационного каталога: категории, товары, сгенерированные фотографии, оптовые цены, модификации, фильтры, промокод и промо-ссылка (идемпотентно) | `--force` (разрешить в production), `--fresh` (удалить старые демо-данные), `--no-images`, `--limit=N` |
| `shop:doctor` | Проверка окружения сервера (TZ 12.4): PHP и расширения, права на каталоги, почта, очередь и cron, PDF (dompdf, `storage/fonts`), коллизии артикулов товаров и модификаций, активный администратор и роли, перенос характеристик | `--json` (машиночитаемый вывод) |
| `shop:expire-reservations` | Снятие просроченных резервов и возврат товара на склад (SF-53) | — |
| `shop:heartbeat` | Запись отметки времени работы планировщика (AD-11) | — |
| `shop:make-demo-import` | Создание демонстрационного файла импорта (около 50 вымышленных товаров) и ZIP-архива с фото | `--dir=examples` |
| `shop:make-template` | Создание шаблона импорта товаров (.xlsx) | `--path=examples/import-template.xlsx` |
| `shop:make-variants-example` | Создание примера импорта с модификациями (футболка «Цвет × Размер» и обычный товар) | `--path=examples/import-variants.xlsx` |
| `shop:notify-expiring-reservations` | Telegram-предупреждение о резервах, истекающих в течение 6 часов, один раз на резерв (AD-10) | — |
| `shop:purge-customer-codes` | Удаление просроченных кодов из писем покупателям (CA-04) | — |
| `shop:purge-unverified-customers` | Удаление аккаунтов, не подтвердивших email за срок хранения (CA-24) | — |
| `shop:rebuild-attribute-cache` | Пересборка JSON-кэша характеристик `products.attributes` из таблиц (FL-04) | — |
| `shop:recalc-prices` | Пересчёт цен товаров в фоне (PR-02) | `--all` (все товары), `--boundaries` (правила, начавшиеся или закончившиеся), `--sync` (сразу, без очереди) |
| `shop:sitemap` | Создание `public/sitemap.xml` (SF-82) | — |
| `shop:variants-rollup` | Пересчёт агрегатов остатков и цен карточек с модификациями, расхождения пишутся в журнал (VR-06) | — |
